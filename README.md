# dentalcraft-web

DentalCraft marketing website: a static site in English and Italian, with its brand kit and media.

> In development · Not a medical device · Not for clinical use

## Layout

| Folder | Content |
| --- | --- |
| `brand/` | Brand kit: guidelines, tokens, SVG/PNG logos, favicons, app icons, Open Graph image |
| `content/` | Site copy (EN/IT) and video script |
| `design/` | FigCraft design source (in progress, not yet tracked) |
| `media/` | Music (`media/music/`, WAV masters excluded, see `.gitignore`) and video |

The site implementation is still to come.

## Part of DentalCraft

This repository is a submodule of the `dentalcraft` superproject, next to `dentalcraft-core`, `dentalcraft-aligners`, `dentalcraft-app` and `dentalcraft-server`.
